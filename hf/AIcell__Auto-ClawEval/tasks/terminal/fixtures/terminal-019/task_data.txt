# Binary Packet Decoder

## Overview

You are working with a proprietary IoT sensor network that transmits data using a compact binary protocol. Your task is to implement a decoder that can parse these binary packets according to the protocol specification below.

## Protocol Specification

### Packet Structure

Every packet follows this structure:

```
+--------+--------+--------+------------------+----------+--------+
| MAGIC  | VER    | TYPE   | PAYLOAD          | CHECKSUM | END    |
| 2 bytes| 1 byte | 1 byte | variable         | 2 bytes  | 1 byte |
+--------+--------+--------+------------------+----------+--------+
```

**Field Descriptions:**

| Field    | Size     | Description                                      |
|----------|----------|--------------------------------------------------|
| MAGIC    | 2 bytes  | Always `0xAB 0xCD` — identifies a valid packet   |
| VER      | 1 byte   | Protocol version (currently `0x02`)              |
| TYPE     | 1 byte   | Packet type (see Packet Types below)             |
| PAYLOAD  | variable | Type-specific data (see Payload Formats)         |
| CHECKSUM | 2 bytes  | Sum of all bytes from VER through end of PAYLOAD |
| END      | 1 byte   | Always `0xFF` — end-of-packet marker             |

### Packet Types

| Type Code | Name        | Description                        |
|-----------|-------------|------------------------------------|
| `0x01`    | SENSOR_DATA | Environmental sensor readings      |
| `0x02`    | DEVICE_INFO | Device identification and metadata |
| `0x03`    | ALERT       | Threshold breach notification      |
| `0x04`    | ACK         | Acknowledgement packet             |

### Payload Formats

#### Type `0x01` — SENSOR_DATA

```
+----------+----------+----------+----------+----------+
| TEMP     | HUMIDITY | PRESSURE | LIGHT    | BATTERY  |
| 2 bytes  | 2 bytes  | 2 bytes  | 2 bytes  | 1 byte   |
+----------+----------+----------+----------+----------+
```

- **TEMP**: Signed 16-bit integer, big-endian. Value in units of 0.01°C (e.g., `0x09C4` = 2500 = 25.00°C)
- **HUMIDITY**: Unsigned 16-bit integer, big-endian. Value in units of 0.01% RH (e.g., `0x1388` = 5000 = 50.00% RH)
- **PRESSURE**: Unsigned 16-bit integer, big-endian. Value in units of 0.1 hPa (e.g., `0x2710` = 10000 = 1000.0 hPa)
- **LIGHT**: Unsigned 16-bit integer, big-endian. Value in lux (e.g., `0x00FF` = 255 lux)
- **BATTERY**: Unsigned 8-bit integer. Value in units of 0.5% (e.g., `0xC8` = 200 = 100.0%)

#### Type `0x02` — DEVICE_INFO

```
+----------+----------+----------+----------+
| DEV_ID   | FW_MAJ   | FW_MIN   | NAME_LEN |
| 4 bytes  | 1 byte   | 1 byte   | 1 byte   |
+----------+----------+----------+----------+
| NAME                                      |
| NAME_LEN bytes                            |
+-------------------------------------------+
```

- **DEV_ID**: Unsigned 32-bit integer, big-endian. Unique device identifier.
- **FW_MAJ**: Unsigned 8-bit integer. Firmware major version.
- **FW_MIN**: Unsigned 8-bit integer. Firmware minor version.
- **NAME_LEN**: Unsigned 8-bit integer. Length of the device name string in bytes.
- **NAME**: ASCII string of NAME_LEN bytes. Device name (not null-terminated).
