# Binary Packet Decoder

## Overview

You are working with a proprietary IoT sensor network that transmits data using a custom binary protocol. Your task is to implement a binary packet decoder that can parse raw byte streams according to the protocol specification below.

## Protocol Specification

### Packet Structure

Every packet follows this structure:

```
+--------+--------+--------+------------------+----------+--------+
| MAGIC  | VER    | TYPE   | PAYLOAD LENGTH   | PAYLOAD  | CRC8   |
| 2 bytes| 1 byte | 1 byte | 2 bytes (LE)     | N bytes  | 1 byte |
+--------+--------+--------+------------------+----------+--------+
```

- **MAGIC**: Always `0xAB 0xCD`
- **VER**: Protocol version (`0x01` or `0x02`)
- **TYPE**: Packet type (see below)
- **PAYLOAD LENGTH**: Little-endian 16-bit unsigned integer
- **PAYLOAD**: Variable-length data (interpreted based on TYPE)
- **CRC8**: CRC-8 checksum of all preceding bytes (MAGIC through end of PAYLOAD)

### Packet Types

| Type Byte | Name          | Description                        |
|-----------|---------------|------------------------------------|
| `0x01`    | SENSOR_DATA   | Environmental sensor readings      |
| `0x02`    | DEVICE_STATUS | Device health and status info      |
| `0x03`    | COMMAND_ACK   | Acknowledgement of a command       |
| `0x04`    | ERROR_REPORT  | Error code and message             |
| `0x05`    | TIME_SYNC     | Timestamp synchronization packet   |

### Payload Formats

#### SENSOR_DATA (`0x01`)

```
+----------+----------+----------+----------+----------+----------+
| DEVICE_ID| TEMP     | HUMIDITY | PRESSURE | LIGHT    | BATTERY  |
| 4 bytes  | 2 bytes  | 2 bytes  | 4 bytes  | 2 bytes  | 1 byte   |
| uint32   | int16    | uint16   | uint32   | uint16   | uint8    |
+----------+----------+----------+----------+----------+----------+
```

- **DEVICE_ID**: Unique device identifier (uint32, little-endian)
- **TEMP**: Temperature in 0.01°C units, signed (int16, little-endian). Value `2315` = 23.15°C
- **HUMIDITY**: Relative humidity in 0.01% units (uint16, little-endian). Value `6842` = 68.42%
- **PRESSURE**: Atmospheric pressure in Pa (uint32, little-endian). Value `101325` = 101325 Pa
- **LIGHT**: Light intensity in lux (uint16, little-endian)
- **BATTERY**: Battery level 0–100 (uint8)

Total payload size: **15 bytes**

#### DEVICE_STATUS (`0x02`)

```
+----------+----------+----------+----------+
| DEVICE_ID| UPTIME   | FLAGS    | FIRMWARE |
| 4 bytes  | 4 bytes  | 2 bytes  | 4 bytes  |
| uint32   | uint32   | uint16   | uint32   |
+----------+----------+----------+----------+
```

- **DEVICE_ID**: uint32, little-endian
- **UPTIME**: Seconds since boot (uint32, little-endian)
- **FLAGS**: Bitmask (uint16, little-endian)
  - Bit 0: GPS lock
  - Bit 1: Radio active
  - Bit 2: Low power mode
  - Bit 3: Error state
  - Bits 4–15: Reserved
- **FIRMWARE**: Firmware version encoded as `(major << 24) | (minor << 16) | (patch)` (uint32, big-endian)

Total payload size: **14 bytes**
