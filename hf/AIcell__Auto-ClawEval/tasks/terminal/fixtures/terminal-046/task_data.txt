id: sqlite-wal-recovery
title: SQLite Database Recovery from WAL Journal
description: |
  A critical SQLite database used by a web application has become corrupted after
  an unexpected system crash. The database was operating in WAL (Write-Ahead Log)
  mode when the server lost power. Your task is to recover the database, merge the
  WAL journal, verify data integrity, and restore full database functionality.

  WAL (Write-Ahead Log) mode is SQLite's default journaling mode for concurrent
  access. When a crash occurs, the WAL file may contain committed transactions
  that haven't been checkpointed back to the main database file. Recovery involves
  merging these changes and ensuring consistency.

type: challenge
difficulty: intermediate
